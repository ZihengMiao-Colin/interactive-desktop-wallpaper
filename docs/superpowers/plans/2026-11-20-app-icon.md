# 软件图标换成 K2 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 安装包、exe、任务栏、托盘、设置窗口标题栏都换成 Kirie 的 K2 图标，每个尺寸都清楚。

**Architecture:** `tools/make_icon.py` 按每个尺寸一套整数参数画三层 K，生成多尺寸 `assets/icon.ico`（每张手画，不缩放）、256px 的 PNG、矢量 SVG 和标题栏用的 20px SVG；打包配置、设置窗口、托盘改用 `.ico`，标题栏 logo 改用 SVG。

**Tech Stack:** Python 3.11 + Pillow 12.3.0（项目 `venv`）、`unittest`；Electron 28、`node --test`。

**Spec:** `docs/superpowers/specs/2026-11-20-app-icon-design.md`

## Global Constraints

- 不加任何依赖（Python 只用 venv 里已有的 Pillow；npm 不加包）。
- 底色 `#0f0f10`；三层 K 从远到近 `#0d5a6e`、`#18d1ff`、`#ffffff`，往右下错开。
- 九个尺寸 16、20、24、32、40、48、64、128、256，参数用设计文档里的表（H、W、S、A、o），三层整体在方块里居中：`x0 = int((g - (W + 2o)) / 2 + 0.5)`，`y0` 同理用 H。
- 不改名：`package.json` 的 `name`、`productName`、界面上的"互动3D壁纸"都不动。
- 代码注释用简体中文。
- 不提交，改完交给用户看。

## Review Focus

1. 屏幕缩放 125% / 150% / 200% 时，Windows 应该从 `.ico` 里挑对应尺寸的手画图，而不是拿 256 缩。测试：`.ico` 里每一帧和 `render(g)` 逐像素相同（Task 1）。开发机只能实测 100%，其他缩放靠这条测试。
2. 打包时 NSIS 读不了 PNG 压缩的图标帧 → 安装包图标失败。`.ico` 一律存 BMP 帧（Task 1），并在 Task 3 真打一次包确认。
3. `.ico` 文件丢了或读出来是空图 → 托盘不能崩，用原来的兜底小圆点（Task 2 测试）。
4. 改了脚本里的参数却忘了重新生成 → 仓库里的图标和脚本对不上。测试：`test_assets_up_to_date`（Task 1）。
5. 日间主题下标题栏 logo 仍是深色方块：设计就是这样，Task 3 截图确认不突兀、不被裁切。

**Files:**

- Create（由脚本生成）: `assets/icon.ico`、`assets/icon.svg`、`assets/icon-20.svg`
- Modify（由脚本覆盖）: `assets/icon.png`

**Interfaces:**
- Produces（`tools/make_icon.py`）:
  - `TILE: str = '0f0f10'`，`LAYERS: list[str] = ['0d5a6e', '18d1ff', 'ffffff']`（从远到近）
  - `K_GRID: dict[int, dict]`：键是尺寸，值是 `dict(H=, W=, S=, A=, o=)`，数值抄设计文档的表
  - `SIZES: list[int] = [16, 20, 24, 32, 40, 48, 64, 128, 256]`
  - `origin(g: int) -> tuple[int, int]`：最前面那层 K 的左上角
  - `k_polys(x, y, H, W, S, A) -> list[list[tuple[float, float]]]`：竖笔、上斜笔、下斜笔三个多边形（和定稿时 `k2_refined.py` 的同名函数一样）
  - `render(g: int) -> PIL.Image.Image`：g×g 的 RGBA 图，按 g 自己那套参数画，超采样后 `BOX` 缩小
  - `to_svg(g: int) -> str`：g 那套参数的 SVG（`viewBox="0 0 g g"`）
  - `build(out_dir: str) -> None`：写 `icon.ico`、`icon.png`（256）、`icon.svg`（256）、`icon-20.svg`（20）
  - 命令行：`venv/Scripts/python.exe tools/make_icon.py [输出目录]`，不给目录就写到仓库的 `assets/`
