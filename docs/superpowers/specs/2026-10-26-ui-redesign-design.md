# 前端界面改版 — 设计

> 2026-10-26。用户把方案交给助手决定，看过浏览器 mockup（`.superpowers/mockups/ui-redesign.html`，不进 git）后确认"按这个做"。

## 为什么改

设置窗口是一条 540px 宽、所有面板展开后约 2700px 高的长页面，由几个模型分别写成，风格不统一：

- 五张卡片从上往下排，"自定义元素"这个功能最多的部分藏在第三张卡片的第四个子页签里。
- 按钮全是同样的大块半透明，emoji 当图标；滑块的数值和标签、滑块之间隔着一大段空白。
- 操作结果只写在页面最底下一行小字里，在上面点了按钮基本看不到。
- 壁纸页上的摆放工具条、Toast、调试面板又是另一套样子。

## 目标

- 视觉和信息结构一起改：左侧导航分页，统一一套控件和图标。
- 让"壁纸动起来是什么样"在设置窗口里就能看到（实时视差预览）。
- 设置窗口和壁纸页（摆放模式、Toast、加载提示、调试面板）用同一套颜色和组件。
- 设置页代码拆开，统一成一种写法。

## 不做（非目标）

- 不改功能和 IPC：`preload.js` 暴露的接口、`config.json` 结构、主进程逻辑都不变（设置窗口的尺寸和标题栏样式除外）。
- 不引入框架和构建步骤，仍是普通脚本 + CSS。
- 不做浅色主题、不做多语言、不改托盘菜单。

## 反目标（做成这样就算失败）

- 任何现有功能在新界面里找不到或者用不了。
- 设置窗口打开后一直占 GPU（预览必须鼠标不动就停帧）。
- 需要联网才能显示图标或字体。

## 视觉规范

颜色（CSS 变量，放在 `ui/tokens.css`，设置窗口和壁纸页共用）：

| 名称 | 值 | 用途 |
|---|---|---|
| `--ink` | `#0b0f15` | 侧边栏、标题栏、分段按钮底 |
| `--bg` | `#10161e` | 内容区 |
| `--surface` | `#161e28` | 列表 / 分组底色 |
| `--raised` | `#1d2733` | 按钮、输入框 |
| `--text` / `--text-2` / `--text-3` | `#e6ebf2` / `#97a3b4` / `#627084` | 正文 / 次要 / 说明 |
| `--accent` | `#7ecfff` | 强调色（沿用原来的） |
| `--success` / `--danger` / `--warn` | `#6fe0a6` / `#ff7d7d` / `#ffcc6a` | 状态；`--warn` 也是自由变形的颜色 |
| `--far` / `--near` | `#161a21` / `#eef2f6` | 深度色带两端 |

- 字体：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`，正文 13px，页面标题 20px/600，分组标题 14px/600，数字用 `tabular-nums`。不打包字体。
- 圆角按层级：大块（预览、列表）12px，控件 8px，标签胶囊 999px。
- 图标：Lucide（ISC 许可）挑需要的几十个，做成内联 `<symbol>` 雪碧图放在 `ui/icons.js`，离线可用。不再用 emoji。
- 标志性元素只有两个，其余保持安静：
  1. **实时视差预览**：预览图随鼠标按当前参数做视差，用的是和壁纸同一个着色器公式（`renderer/shaders.js` 的 `PARALLAX_GLSL`）和同一套映射（`Shared.parallax`）。
  2. **深度色带**：所有调"深度"的滑块（对焦深度、元素深度、摆放工具条深度、调试面板对焦深度）轨道画成左远右近的深度图渐变，两端标"远 / 近"。

## 设置窗口

窗口：约 960×660，最小 820×560，可调大小；深色标题栏（`titleBarStyle: 'hidden'` + `titleBarOverlay`，保留系统的最小化 / 最大化 / 关闭），`backgroundColor` 设成背景色避免白屏闪一下。

```
┌──────────────────────────────────────────────────────────────┐
│ ▣ 互动 3D 壁纸                                    ─  ☐  ✕   │ 标题栏（可拖动）
├────────────┬─────────────────────────────────────────────────┤
│ 壁纸        │  页面内容（每页一个 <section>，内容区单独滚动）    │
│ 视差        │                                                 │
│ 元素    2   │                                                 │
│ 特效        │                                                 │
│ 唱片机      │                                                 │
│            │                                                 │
│ [缩略图]    │                                                 │
│ 正在使用 …  │                                      [Toast]    │
│ 设置        │                                                 │
└────────────┴─────────────────────────────────────────────────┘
```

- 左侧导航六页：壁纸、视差、元素（右侧显示壁纸上的元素个数）、特效、唱片机，底部是"正在使用"的壁纸卡片（点它回到壁纸页）和"设置"。
- 操作反馈：原来的 `setStatus(msg, cls)` 保留签名，改成窗口右下角的 Toast（成功 / 普通 3 秒，错误 6 秒，新的顶掉旧的）。
- 用词改成白话："阻尼平滑度"→"跟手程度"，参数下面加一行说明。

### 壁纸页
- 大预览（实时视差）。左上角提示"把鼠标移到图上，看壁纸动起来的样子"，鼠标移上去后淡出；右上角"原图 | 深度图"切换（有深度图才出现）；左下角名称、"默认壁纸 / 你的图片"标签、分辨率，正在使用的那张加"使用中"。没有深度图时预览不动，提示改成"生成深度图后可以预览视差"。
- 预览下面一条操作栏：左边深度图状态（已就绪 / 未生成 / 生成中带进度条和进度文字），中间"边缘平滑"滑块（只影响生成，从原来的位置挪到这里），右边"生成深度图""应用壁纸"（主按钮）。
- 下面平铺默认壁纸图库（不再折叠），最后一格是"从电脑选择…"。

### 视差页
- 上面是同一个实时预览（小一点），下面三行：视差强度、跟手程度、对焦深度（深度色带）。右上角"恢复推荐值"（仍然同时恢复边缘平滑）。

### 元素页
- 右上角"添加素材"。
- 素材库：默认元素和自己添加的放在同一个网格里，悬停显示"放到壁纸上"，自己添加的悬停时右上角有移除按钮，文件丢失的标红；最后一格"添加素材"。
- 壁纸上的元素：左右两栏。左边列表（缩略图、名称、播放方式摘要、显示 / 隐藏按钮），右边是选中元素的调整面板：标题行有"重新摆放"、显示 / 隐藏、删除；分组为位置（深度、不透明度）、颜色（色相、饱和度、亮度、染色颜色和强度、恢复原色）、播放（循环 / 间隔播放 / 点击播放分段按钮，间隔秒数，点击播放的"在点击位置出现"）、绿幕抠像（开关 + 强度）。图片素材没有播放和抠像两组（和现在一致）。
- 没有元素时右栏显示引导文字。

### 特效页
- 天气：六个图标格子（无、细雨、落雪、落樱、枫叶、光斑），密度用分段按钮，飘落速度滑块，"粒子跟着视差移动"开关。
- 视频特效：总开关在分组标题右边，关掉时下面变暗但仍可点（点预设会自动打开，和现在一致）。预设卡片网格，卡片右下角标"滤色 / 绿幕"。下面是"自己的视频"（导入、使用这个视频）、混合方式分段按钮、不透明度、播放速度。

### 唱片机页
- 右上角总开关。"正在播放"卡片：唱片（中间贴当前封面）、曲名和状态、"导入音乐…"、圆形播放 / 暂停按钮。
- 音量、位置（迷你屏幕点四个角，代替下拉框）、大小、唱片封面（缩略图 + 更换 / 用默认）。

### 设置页
- 开机自动启动。深度图缓存：存放位置（点击打开）、打开文件夹、更改位置、清除缓存（仍先确认）。

## 壁纸页（`index.html` / `style.css`）

- 共用 `ui/tokens.css` 和 `ui/icons.js`。
- 摆放模式：顶部毛玻璃提示胶囊，先写"摆放「名称」"，按键用键帽样式；选框强调色实线，角点白色方块、边点小胶囊、旋转点强调色带连线，自由变形的点和轮廓用 `--warp`（琥珀色）；工具条毛玻璃，深度色带滑块 + 数值 + "自动"标签，翻转只留图标（带 title），自由变形开着时按钮变琥珀色，确认用强调色。
- Toast、加载提示、初始化失败提示、调试面板统一成毛玻璃样式；调试面板的折叠按钮改成箭头图标。

## 代码组织

- `ui/tokens.css`：颜色、字体、圆角变量和两个页面都用的基础控件样式（滑块、深度色带、按钮、开关、分段按钮、键帽、毛玻璃）。
- `ui/icons.js`：Lucide 雪碧图，加载时插入页面；`Icons.svg(name)` 生成 `<svg><use></svg>`。
- `settings.html` 只留结构；样式搬到 `settings/settings.css`；内联脚本按页面拆到 `settings/` 下（导航和 Toast、壁纸页、视差页、特效页、唱片机页、设置页），`depth-preview.js` 改成实时预览，`elements-tab.js` 和 `gallery-panel.js` 按新结构重写渲染部分。
- 原有逻辑（选择 / 生成 / 应用的状态机、节流保存、托盘转过来的图片、配置回填）照搬，只换 DOM。
