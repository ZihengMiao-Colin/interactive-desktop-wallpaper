# 视频壁纸 + 我的壁纸 — 设计

> 2026-11-02。用户想把视频直接设成桌面壁纸。现在只有图片能当壁纸（带深度视差），GIF、视频只能在「元素」里叠在壁纸上，或者用「特效」里的全屏视频特效盖一层。讨论过程中看了四版壁纸页示意图，入口定为第五版（「从电脑选择…」放进一直显示的「我的壁纸」）。示意图在 `.superpowers/brainstorm/`（被 .gitignore 忽略），本文用文字写清楚，不依赖那些文件。

## 为什么做、做成什么样

- 这是一个**单独加的功能**：给用户多一个选择，能用自己的视频当壁纸。重点是"能把视频设成壁纸"，跟鼠标动的效果只是附带的尝试，做不好不影响主体。
- 视频不能逐帧生成深度图（太慢、相邻帧深度不一致会闪），所以动态效果用两个便宜的办法：整段视频共用一张深度图（3D 视差），或者整个画面跟着鼠标平移（整体平移）。用户也可以选"不动"，原样播放。
- 顺带做「我的壁纸」：用户自己选过的图片和视频都留在壁纸页，一点就能换回来（现在自己的图片用过就没了，要重新去文件夹里找）。

## 目标

1. 用户能选一个本地视频设成桌面壁纸，循环播放，铺满屏幕（和图片一样按 Cover 方式裁切）。
2. 每个视频有三种效果：**不动**（默认）、**3D 视差**、**整体平移**，每个视频各记各的。
3. 每个视频有声音开关，默认静音，各记各的。
4. 壁纸页加「我的壁纸」：用户自己的图片和视频放在一起，一点就能选中，悬停出现 × 可以移除。
5. 唱片机、元素、天气、全屏视频特效都能叠在视频壁纸上。
6. 设置页预览能播放选中的视频，并显示所选效果。

## 不做

- 逐帧深度图。
- 托盘「更换壁纸」选视频：托盘还是只能选图片（选的图片会进「我的壁纸」）。
- 安卓版不跟着做。
- 不复制视频文件，只记路径（和现在的图片壁纸一样）。
- 不做剪辑、裁剪、调速、音量滑块。
- 图片不加"不动 / 整体平移"，图片还是只有 3D 视差。

## 做出来也算失败的情况

- 不用视频的用户觉得壁纸页变乱，或者图片壁纸变卡、变耗电（图片壁纸的空闲停帧必须照旧生效）。
- 图片壁纸现有的行为变了：视差效果、深度图生成、默认壁纸、元素遮挡、托盘换图。
- 没开声音的视频在被挡住、锁屏时还在后台解码；开了声音的视频在锁屏、睡眠时还出声音。
- 老用户升级后当前壁纸丢了，或者配置读坏了。
- 把新功能和「特效」里的"视频特效"（盖在壁纸上的一层）搞混：两者是不同的功能，界面用词要分开（新功能叫"视频壁纸 / 你的视频"）。

## 壁纸页（设置窗口）

从上到下：预览 → 操作栏 → **我的壁纸** → 默认壁纸。

**我的壁纸**
- 一直显示，第一次打开时只有一格「从电脑选择… / 图片或视频」。这一格永远是这一栏的第一格。
- 后面按最近用过的排：最近加入或最近应用的在前。
- 视频缩略图左下角标 ▶ 和时长；文件找不到的格子显示"找不到文件"，可以移除。
- 悬停一格时右上角出现 ×：从列表里移除，不删原文件。移除正在使用的那一个也可以，桌面上不受影响，直到换了别的壁纸。
- 标题旁的小字："只记住位置，原文件挪走后会失效"。
- 内容多过一行时，可以只显示一行加"展开"，免得把默认壁纸挤得太远（实现时看情况决定）。

**默认壁纸**：去掉原来第一格「从电脑选择…」，其余不变。

**选择对话框**：一个对话框，图片和视频都能选。过滤器第一项"图片和视频"（jpg、jpeg、png、webp、bmp、mp4、webm、mov、m4v、mkv），另外两项"图片""视频"。

**选中一个视频后**（选中只是预览，和图片一样要点"应用壁纸"才换到桌面上）
- 预览开始循环播放（预览一直静音），上面标"你的视频"。
- 操作栏换成：`效果 [不动 | 3D 视差 | 整体平移]`　`声音 [开关]`　……　`[应用壁纸]`
  - 不动、整体平移：可以直接应用。
  - 3D 视差：和图片一样，显示深度图状态（已就绪 / 还没有深度图 / 平滑改了需要重新生成）、边缘平滑滑块、「生成深度图」按钮；有深度图后才能应用。
- 改效果或声音立刻存进这个视频的记录里；要点"应用壁纸"才影响桌面。选中的正好是桌面上正在用的视频时，改了效果或声音后"应用壁纸"变成可点。
- 预览按所选效果跟着鼠标动（不动就不动），3D 视差时右上角的"原图 | 深度图"切换照常可用。

**选中图片**：和现在完全一样。

**加入「我的壁纸」的时机**
- 从对话框选中、并且确认能读（图片能解码 / 视频能读出第一帧）后立刻加入，不用等应用。读不了就不加，提示条报错。
- 托盘「更换壁纸」选的图片也加入。
- 已经在列表里的（按路径比较，不分大小写和斜杠方向）不重复加，只更新"最近用过"。

**正在使用卡片**（侧栏底部）：视频显示它的缩略图和文件名。

**视差页**：当前壁纸是视频时——
- 不动：页面上提示"当前视频壁纸设为不动，这些设置不起作用"。
- 整体平移：视差强度、跟手程度起作用，对焦深度不起作用（提示一句）。
- 3D 视差：和图片一样。

## 三种效果在桌面上的表现

| | 画面 | 元素 | 遮挡 | 自动贴地 |
|---|---|---|---|---|
| 不动 | 原样播放，不跟鼠标 | 不跟鼠标移动，只按自己的播放方式播放 | 没有 | 没有深度图，不起作用 |
| 3D 视差 | 和图片壁纸一样做视差，深度图整段共用 | 和图片壁纸一样 | 有 | 有（用这张深度图） |
| 整体平移 | 整个画面跟着鼠标平移 | 和画面一起平移，看起来贴在视频上 | 没有 | 不起作用 |

- 天气：三种效果下都照常显示，"粒子跟着视差移动"还是天气自己的开关。
- 唱片机、全屏视频特效：不受影响。
- 整体平移时画面要略微放大，保证移到最边上也不露出边缘拉伸的像素。移动幅度用「视差强度」，平滑用「跟手程度」。
- 不动、整体平移时摆放窗口里的"自动贴地"：没有深度图可取，实现时决定是禁用这个选项还是给一个固定深度，但不能报错或卡住。

**3D 视差的深度图**
- 从视频里取画面生成一张深度图，走现有的深度图生成（ONNX 子进程），边缘平滑滑块照常起作用。
- 取哪一帧由实现时对比决定：可以取一帧（避开开头的黑场），也可以取几帧逐像素取中位数，合成一张没有移动物体的干净画面。
- 存进现有的深度图缓存（按文件路径 + 大小 + 修改时间），「清除缓存」会一起清掉，之后这个视频的 3D 视差显示"还没有深度图"。

**声音**
- 默认关。打开后桌面上的视频壁纸放出原声，音量就是视频本身的音量，不另做滑块。
- 唱片机同时在放音乐时两个都会响，由用户自己决定开哪个。
- **被窗口挡住时声音继续放**（用户定的）。现有的全屏检测是"前台窗口盖住屏幕 90% 以上"，普通最大化的窗口也算，所以要把"停画面"和"停播放"分开：
  - 全屏检测触发的暂停：停止重画；开了声音的视频继续播放（声音不断），没开声音的视频暂停。和唱片机现在的行为一致。
  - 锁屏、睡眠、摆放模式：视频暂停，声音停。
  - 主进程发 `renderer:pause` 时要带上原因，渲染进程据此决定视频停不停。
  - 全屏检测本身不改，图片壁纸的暂停方式不变。

## 出问题时

- **格式放不了**：选中时读不出来（超时或报错），提示条显示"这个视频格式不支持，换成 MP4 或 WebM 试试"，不加进列表。
- **原文件被挪走或删掉**：
  - 「我的壁纸」里那一格显示"找不到文件"，点它提示一句，不报错。
  - 启动时上次的壁纸（图片或视频）找不到：和现在一样退回自带的 `background.png`，另外弹一个提示"找不到上次的壁纸：<文件名>"（现在图片丢了是静默退回的，顺手一起加上）。
- **播放中途解码出错**：画面停在最后一帧，记日志，不弹窗。

## 数据

配置里加一段（名字实现时可以调整，要求是下面这些信息都在）：

```js
myWallpapers: [
  { path, type: 'image' | 'video', lastUsedAt,      // 按 lastUsedAt 从新到旧排
    thumb,                                          // 视频的缩略图文件（数据目录里）；图片可以不存，直接用原图或现有缩略图办法
    effect: 'none' | 'depth' | 'pan',               // 只有视频有，默认 'none'
    sound: false },                                 // 只有视频有，默认 false
]
```

- 当前壁纸：**`currentImage` 只放图片**，当前视频另开一个字段（比如 `currentVideo: { path, effect, sound, imageAtTime }`）。原因：开发版和安装版共用同一个数据目录，这台电脑上还装着已发布的 v1.1.0；旧版本会把 `currentImage` 指向的文件整个读成 base64，指向几百 MB 的视频会卡住或失败。（助手定的）
  - 应用视频时只写 `currentVideo`，`currentImage` 保持原来那张图，同时把当时的 `currentImage` 记进 `imageAtTime`。
  - 新版本启动：有 `currentVideo`、并且 `imageAtTime` 和现在的 `currentImage` 一致 → 用视频；不一致说明之后旧版本换过图片 → 以 `currentImage` 为准，清掉 `currentVideo`。
  - 应用图片时清掉 `currentVideo`。
  - 旧配置（只有 `currentImage`，指向默认壁纸或用户图片）照常读。来回切换的情况要有单元测试。
- 桌面上实际在用的效果和声音：要和"列表里存的设置"分开记（因为改了设置要点应用才生效）。
- 升级迁移：启动时如果 `currentImage` 不是默认壁纸、文件也还在，把它加进 `myWallpapers`。
- 视频缩略图存在数据目录下（比如 `wallpaper_thumbs/`），移除条目时一起删。卸载时选"删除我的数据"本来就会删整个数据目录，不用改卸载脚本。
- 移除条目时不删它的深度图缓存（清除缓存时统一清）。
- 列表的纯逻辑（加入、去重、排序、移除、迁移）放进 `shared/`，写单元测试，和 `shared/playlist.js` 一样的做法。

## 渲染和性能（壁纸窗口）

- 视频用隐藏的 `<video>`（`loop`，声音按设置）做 Pixi 纹理，替换背景滤镜的 `uImage`；做法参考元素的视频源 `renderer/elements/sources.js`，路径用 `Host.fileUrl`。
- 换壁纸时释放旧视频（停播、清掉 `src`）和旧纹理，和现在换图片释放旧纹理一样。
- **停帧**：视频壁纸要一直出帧，但只在有新视频帧或鼠标在动时才需要画。用 `requestVideoFrameCallback` 叫醒，帧率上限仍是 60；30fps 的视频大约按 30fps 画。图片壁纸的空闲停帧不能受影响。
- 主进程发暂停时停止重画；视频停不停按上面"声音"一节的规则（开了声音、又只是被窗口挡住时继续播放），恢复时接着播。
- 不转码。4K 视频解码开销大是视频本身的代价，不额外处理。

## 设置页预览（`settings/depth-preview.js`）

- 预览是直接用 WebGL 写的，要加视频纹理：播放时每帧从 `<video>` 上传纹理。
- 一直静音。
- 设置窗口隐藏、或者切到不显示预览的页面时，暂停视频、停止重画。

## 现有代码大概要动的地方

- `main.js`：选择对话框（图片 + 视频）、`applyWallpaper` 要带上类型 / 效果 / 声音、托盘换图加进列表、启动迁移。
- `preload.js`：3D 视差的深度图要从视频里取画面；现在的 `decodeImagePixels` 只能解图片，取视频画面可以在设置窗口里用 `<video>` + canvas 做，再把像素交给 `depth:generate`。
- `renderer/parallax-scene.js`：`load` 支持视频源；支持"不动""整体平移"两种不用深度图的模式。
- `renderer/main.js`：`onNewImage`、`resolveInitialSources` 支持视频和找不到文件的提示；`sleepIfIdle` 考虑视频。
- `renderer/elements/elements-layer.js`、`renderer/edit-mode.js`：没有深度图时不做遮挡，自动贴地不出错。
- `settings/wallpaper-page.js`、`settings/gallery-panel.js`、`settings.html`、`settings/settings.css`：「我的壁纸」、添加格挪位置、视频的操作栏。
- `settings/parallax-page.js`：当前是视频时的提示。
- `settings/thumbnail.js`：已有取视频帧做缩略图的代码，可以复用。
- `src/store.js`：默认配置、迁移、缩略图目录。
- 文档：`PROJECT_NOTES.md` / `.en.md`、`README.md` / `.en.md`。
