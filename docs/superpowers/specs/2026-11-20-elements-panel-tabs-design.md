# 元素调整面板改成分页（短设计）

日期：2026-11-20

## 为什么改

设置窗口"元素"页右边的单个元素调整面板太大：四组设置（位置、颜色、播放、绿幕抠像）竖着排成一长条，GIF / 视频元素约 566px 高。默认窗口（960×660）下面板从 410px 处才开始，不滚动只看得到"深度"和"不透明度"；全屏时面板跟着拉宽，占一大块地方；左边元素列表每行比列表宽 16px，压到了面板底下。

## 目标

- 默认窗口大小下不用滚动就能看全面板。
- 全屏时面板不再一路拉宽。
- 左边列表不再和面板重叠。

## 不做

- 不动素材库卡片、页面标题和左边列表的样子（只修重叠）。
- 不改任何设置项的含义、范围和保存方式，也不加新设置。

## 不能出现的情况（做了也算失败）

- 拖滑块拖到一半面板被重绘、标签跳回第一个（现在靠 `hold()` 推迟重绘，分页后要保持）。
- 收到配置广播重绘后，当前标签丢了。

## 考虑过的做法

| 做法 | 说明 | 结论 |
|---|---|---|
| A. 分页 | 标题栏下一排标签，一次只显示一组 | **用户选了这个**：唯一能在默认窗口下不滚动看全的 |
| B. 压紧 + 宽屏两列 | 四组都在，窄时一列 | 小窗口仍有约 420px，默认窗口还要滚 |
| C. 折叠分组 | 默认只展开"位置" | 展开多了又变长 |

## 怎么做（用户定的）

- 面板标题栏（名称、类型、重新摆放、显示 / 隐藏、删除）不变，下面加一排标签：位置 / 颜色 / 播放 / 抠像，一次只显示一组。图片元素只有"位置""颜色"两个标签。
- 面板最大宽度约 520px；行高 36px → 约 30px，留白减半。
- 修左边列表的重叠：列表的网格列被最长的名字撑宽了，改成 `minmax(0, 1fr)`。

## 我做的决定（可以改）

- **当前标签记在页面状态里**：切换选中的元素、收到配置广播重绘时都保持同一个标签；切到图片元素而当前是"播放"或"抠像"时，退回"位置"。不存到硬盘，关掉设置窗口后回到"位置"。
- **"恢复原色"放到标签栏右端**，只在"颜色"标签下显示，不多占一行。"抠像"标签里第一行是"启用"开关，打开后才显示"抠像强度"。
- **标签上的小圆点**：颜色调过（和默认值不同）时"颜色"标签带一个主色小点，抠像打开时"抠像"标签带小点，免得藏起来的设置被忘掉。
- **标签内容区给最小高度**（按最高的"颜色"一组），切标签时面板不忽高忽低。
- 标签用 `role="tablist" / "tab" / "tabpanel"`，左右方向键可以切换。样式沿用现有的直角、主色色条风格（`ark-style-ui`）。
