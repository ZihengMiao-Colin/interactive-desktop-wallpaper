# 自定义元素系统 — 设计文档

> 日期：2026-10-25
> 状态：待确认
> 相关：`PROJECT_NOTES.md` §9 阶段 2；mockup 存在 `.superpowers/brainstorm/`

标注约定：**【用户决定】** 是用户明确说过的；**【我的决定】** 是设计者替用户拍板的，用户可以推翻；其余未标注的细节留给实现者。

---

## 1. 意图

让用户把自己电脑里的图片、GIF、视频（包括绿幕视频）作为"元素"放到视差壁纸上，并且让这些元素**融入 2.5D 场景**：随鼠标产生和背景一致的视差，被壁纸里更近的物体遮挡。软件自带一批默认元素（先放 `elements/bomb1.mp4`、`bomb2.mp4` 两个爆炸），让用户上手就能体验。

这一版只做基础功能（添加、摆放、确认、基础属性），但数据结构要为以后的变色、旋转、变形留好位置。【用户决定】

## 2. 用户流程【用户决定】

1. 设置窗口"自定义元素"页，点"添加自定义元素"，从电脑里选文件。
2. 选中的文件出现在元素栏（素材库）里。元素栏里同时有一组默认元素。
3. 点元素栏里的某个元素，它出现在当前壁纸上，进入摆放模式。
4. 用户拖拽移动位置，点"确认"后位置固定。

补充：
- 可以同时放多个元素。【用户决定】
- 同一个素材可以在壁纸上放多份，每份有自己的位置和属性。（用户在 mockup 中看过并认可）
- 需要深度遮挡。【用户决定】

## 3. 目标 / 非目标 / 反目标

### 目标（v1）
- 支持格式：静态图片（png / jpg / jpeg / webp / bmp）、动图（gif、动态 webp、apng）、视频（mp4 / webm；mov、mkv 能播就支持，播不了给出友好提示）。
- 素材库：默认元素 + 用户导入的元素；可以从库里移除用户导入的元素。
- 壁纸上的元素：新增（从库里点击）、重新摆放、显示/隐藏、删除。
- 每个元素的基础属性：位置、大小、深度、不透明度、播放方式、绿幕抠像。
- 视差与深度遮挡和背景完全一致。
- 全屏应用暂停、锁屏暂停时，元素的视频和计时器一起暂停。
- 配置持久化，重启后保持。

### 非目标（v1 不做）
- 变色、旋转、变形、运动路径、关键帧动画（以后做，但数据结构预留）。
- 点击桌面触发播放（需要全局鼠标钩子，以后再说）。
- 自选抠像颜色（v1 只抠绿色）。
- 多显示器（和项目现状一致，只处理主显示器）。
- 把现有"视频特效"（全屏覆盖层）并进这个系统。它仍然是独立的全屏效果。
- 元素自带声音（视频一律静音）。
- 打包相关（项目当前暂不打包）。

### 反目标（做出来也算失败的情况）
- 元素像"贴在玻璃上"：视差和背景对不上，或者遮挡关系明显错位。
- 摆放模式退出后留下一个置顶窗口，挡住桌面或吃掉鼠标。任何情况下（确认、取消、Esc、渲染进程崩溃）摆放窗口都必须关闭。
- 用户把原文件挪走或删掉后，元素就坏了。
- 放了几个静态图片元素后，鼠标不动时 GPU 占用明显上升。

## 4. 约束

- Electron 28（Chromium 120），Pixi.js 7.4.2，仅 Windows。
- 壁纸窗口挂在 WorkerW 层，**收不到任何鼠标事件**；鼠标位置靠主进程轮询。
- 沿用现有架构：`main.js` 注册 IPC、`preload.js` 暴露 `window.electronAPI`、`src/store.js` 存配置、`config:save` 后主进程广播 `config:load` 给壁纸窗口。
- 当前工作区有大量未提交的 WIP（唱片机、视频特效、天气、贴纸）。开始实现前先把 WIP 提交（`PROJECT_NOTES.md` 阶段 0），这个功能在其基础上开发。
- 代码注释用中文（见 `CLAUDE.md`）。

## 5. 设计

### 5.1 设置窗口【用户决定 + mockup】
- "壁纸自定义元素"区域里，用新的"自定义元素"页**替换现有的"自定义贴纸"页**（贴纸本质上就是一个图片元素）。（用户在 mockup 中看过并认可）
- 页面自上而下：
  1. "＋ 添加自定义元素"按钮（文件对话框按上面的格式过滤）。
  2. 元素栏：先"默认元素"，再"我添加的"。每格显示缩略图、名称、类型标签（图片 / GIF / 视频）。用户导入的元素可以从库里移除。
  3. "壁纸上的元素"列表：每行显示缩略图、名称、播放方式摘要，以及"显示/隐藏""重新摆放""删除"。展开一行可以调深度、不透明度、播放方式、间隔、绿幕开关和抠像强度。
- 库里的元素如果已经放在壁纸上，移除前要确认，确认后连同壁纸上的实例一起删掉。【我的决定】

### 5.2 摆放模式【我的决定】
mockup 里画的是"透明编辑层盖在桌面上，底下壁纸跟着动"。实际做法要调整：桌面上通常开着别的程序窗口，会挡住壁纸，透明层下面看到的不一定是壁纸。所以改为：

- 主进程新建一个**全屏、置顶、无边框、可获得焦点**的摆放窗口（主显示器 bounds），加载壁纸页面的"编辑模式"。它完整渲染当前壁纸场景（背景视差冻结在中心，即 `uMouse = 0`），包括所有已放置的元素和深度遮挡，效果和真实壁纸一致。
- 正在摆放的元素外面有虚线框和四个角点：
  - 拖动框内：移动位置。
  - 拖动角点：等比缩放。
- 元素旁边的浮动工具条：深度滑块（拖动时实时看到遮挡变化）、"✓ 确认"、"✕ 取消"。
- 快捷键：Enter 确认，Esc 取消。
- 确认：保存这个元素，关闭摆放窗口，壁纸立即更新。取消：新元素丢弃；"重新摆放"的元素恢复原状。
- 摆放窗口的渲染进程崩溃或卡死时，主进程必须关闭它，不能留下置顶窗口。
- 这个窗口打开时，桌面图标和任务栏会被盖住，这是预期行为。
- 摆放期间暂停真实壁纸的渲染，避免同时跑两个 WebGL 场景；关闭摆放窗口后恢复。【我的决定】
- 缩放范围限制在屏幕宽度的 3%~150%。【我的决定】
- 确认后主进程除了广播给壁纸窗口，也要通知设置窗口刷新"壁纸上的元素"列表（现在 `config:save` 只广播给壁纸窗口）。

### 5.3 默认值【我的决定】
- 新元素出现在屏幕中央，宽度为屏幕宽度的 25%（保持原始宽高比）。
- **深度自动贴地**：新元素在摆放时，深度会自动跟随"元素底边中点所在位置的壁纸深度"，所以放在山上就站在山上，近处的东西会挡住它。用户一旦手动拖过深度滑块，就改为固定值，不再自动跟随。
  - 自动跟随只在摆放过程中生效。确认后保存的是具体数值；之后换了壁纸，元素也保持这个数值，不会重新取样。
- 多个元素叠在一起时，按深度排序，近的画在上面；深度相同时，后添加的在上面。
- 播放方式可选项：静态图片只有"静止"；动图和视频可选"循环"或"间隔播放"。
- 播放方式默认值：
  - 静态图片：静止（无播放选项）。
  - GIF / 动态 webp / apng：循环。
  - 用户导入的视频：循环。
  - 默认元素按各自的配置。两个爆炸是"间隔播放"：每 10 秒播放一次，带 ±3 秒随机抖动；播完隐藏，下次播放前不显示。
- 绿幕抠像：默认元素按配置开启；用户导入的视频默认关闭，用户自己打开。
- 不透明度 100%。

### 5.4 素材文件管理【我的决定】
- 用户导入的文件**复制**到 `userData/custom_elements/` 下（文件名加唯一 id，避免重名），元素引用这份副本。原文件之后挪走或删掉都不影响。
- 从库里移除用户元素时，同时删除这份副本。
- 默认元素放在项目的 `elements/` 目录，由 `elements/manifest.json` 描述（id、名称、文件、类型、缩略图、默认播放方式、间隔、是否抠像、抠像强度、默认大小）。以后要增加默认元素，只需要放文件并在 manifest 里加一条，不用改代码。
- **默认爆炸素材要先裁剪**：`bomb1.mp4`、`bomb2.mp4` 是 2560×1440 全画面，爆炸只占其中一角（bomb1 偏左上，bomb2 在中下）。直接用的话，元素框远大于爆炸本身，拖动的框中心也不在爆炸上，"贴地"取样点也不对。用 ffmpeg 把每段裁到爆炸和烟雾实际覆盖的区域，顺便降到合适的分辨率，manifest 指向裁剪后的文件；原文件保留。【我的决定】
- 缩略图：默认元素用预先生成的缩略图（本机有 ffmpeg，可以照 `overlay/*_thumb.jpg` 的做法生成）；用户导入的元素在导入时由渲染进程生成（图片缩放、视频取第一帧），存到 `custom_elements/` 里。

### 5.5 数据结构
存在 `config.json` 的 `customElements` 下（`store.js` 的默认配置和合并逻辑要相应支持；数组整体替换，不做深合并）：

```js
customElements: {
  // 用户导入的素材；默认素材来自 elements/manifest.json，不存在这里
  library: [
    { id, name, type: 'image' | 'animated' | 'video', file, thumb, importedAt }
  ],
  // 壁纸上的元素实例
  instances: [
    {
      id,
      assetId,                 // 指向 manifest 或 library 里的素材
      visible: true,
      transform: {             // 以后的旋转、变形都放这里
        x, y,                  // 元素中心点，相对主显示器的归一化坐标 0~1
        width,                 // 相对屏幕宽度的比例；高度按素材宽高比推算
        rotation: 0,           // v1 固定为 0，预留
      },
      depth,                   // 0（最远）~ 1（最近）
      depthAuto: true,         // true 表示深度仍跟随贴地取值
      opacity,                 // 0~1
      playback: { mode: 'static' | 'loop' | 'interval', intervalSec, jitterSec },
      chroma: { enabled, strength },
      effects: {},             // 预留给以后的变色等效果
    }
  ]
}
```

坐标和大小用归一化值，换分辨率后位置和比例不变。

### 5.6 渲染
- 元素在 **Pixi 场景内**渲染：在 `screenSprite` 之上加一个元素容器，每个实例一个 sprite。只有这样才能读到同一张深度纹理来做遮挡。现有的天气、视频特效、唱片机层仍在 Pixi canvas 之上，所以它们会盖在自定义元素前面，这是预期行为。
- **视差**：元素在屏幕上的偏移必须和背景着色器在同一深度处的位移完全一致，包括 `(depth - uFocus)` 公式、软截断、Cover 缩放换算，否则元素会"漂"。建议把背景位移的计算抽成一处，背景和元素共用。
- **深度遮挡**：元素的每个像素先算出它在屏幕上的位置，再采样背景在该处实际显示的深度（考虑背景的视差位移）；元素深度小于场景深度时（场景更近）这个像素被挡住。边缘用小范围 `smoothstep` 过渡，避免锯齿；贴地时加一个小偏移，避免底边自己挡住自己。
- **绿幕抠像**：复用 `VideoOverlayManager` 里已有的抠像算法（`G - max(R, B)` + 去溢色），抽成共享的 shader 片段，"抠像强度"映射到阈值。抠像、遮挡、不透明度在同一个元素 shader 里完成。
- **素材解码**：
  - 静态图片：`PIXI.Texture.from`。
  - 视频：隐藏的 `<video>`（静音、`playsinline`）作为纹理源。
  - 动图：Pixi 7 不能直接播放 GIF。用 `@pixi/gif`（与 Pixi 7 对应的版本），或用 Chromium 自带的 `ImageDecoder`（WebCodecs）解码成帧，由实现者选择。

### 5.7 播放与性能
- 间隔播放：两次播放之间暂停视频、隐藏 sprite，不更新纹理。
- 静态图片元素不应该让渲染循环一直满帧跑。和 `PROJECT_NOTES.md` 阶段 3 的"空闲降帧"一起考虑：只要有正在播放的视频 / 动图，ticker 就保持运行；全是静态元素且鼠标不动时可以停。
- 收到 `renderer:pause` 时暂停所有视频、动图和间隔计时器；`renderer:resume` 时恢复。
- 素材加载失败（格式不支持、文件损坏）时：库里标红并提示，壁纸上跳过这个实例，不影响其他元素。

### 5.8 现有"自定义贴纸"的迁移【我的决定】
首次启动新版本时，如果旧配置里 `sticker.enabled` 为真且图片还存在，就把它导入素材库，并按原来的位置、大小、深度、不透明度生成一个实例；之后删除旧的贴纸配置。然后删除 `StickerManager`、贴纸相关 DOM / CSS、设置页的贴纸 tab 和 `dialog:selectSticker`。

## 6. 留给实现者的选择
- GIF 解码方案（`@pixi/gif` 还是 `ImageDecoder`）。
- 编辑模式的实现方式：同一个 `index.html` 加 query 参数，还是单独的 `edit.html` 复用渲染代码。
- IPC 通道命名、实例 id 生成、副本文件命名。
- shader 组织方式（每个实例一个 filter，还是一个共享 shader 加 uniform）。
- 元素数量是否设软上限，以及超过时是否提示。

## 7. 完成标准
1. 能导入 png、jpg、webp、gif、动态 webp、mp4、webm；不支持的文件给出中文提示。
2. 两个默认爆炸元素在元素栏里显示缩略图。
3. 点元素 → 摆放窗口打开 → 拖动、缩放、调深度 → 确认 → 壁纸上出现在同一位置，重启后还在。
4. Esc、取消、渲染进程崩溃都不会留下置顶窗口。
5. 同一个素材可以放两份，各自独立。
6. 移动鼠标时，元素和它所在深度的背景一起移动，没有相对漂移；更近的场景会挡住元素。
7. 爆炸元素按间隔播放，绿色被抠掉，两次播放之间不显示。
8. 原文件删掉后，已导入的元素仍然正常。
9. 全屏应用时元素视频暂停，退出全屏后恢复。
10. 旧贴纸配置被迁移成一个图片元素，贴纸 tab 已移除。
