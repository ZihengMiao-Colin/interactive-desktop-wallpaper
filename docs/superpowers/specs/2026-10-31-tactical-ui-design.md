# 界面改成战术终端风格 — 设计

> 2026-10-31。用户用自己写的个人 skill `ark-style-ui`（参考明日方舟 UI 的"战术终端 / 工业科幻"设计语言，默认是安静克制的一版）让助手重做前端。看过设置窗口六个页面的截图后说"保留，继续完善"，于是又补了壁纸页浮层、界面主题和自带宋体。

## 目标

- 只换外观：页面结构、类名、JS、IPC 沿用 10-26 改版（[2026-10-26-ui-redesign-design.md](2026-10-26-ui-redesign-design.md)）。唯一新增的功能是界面主题（夜间 / 日间 / 跟随系统）。
- 设置窗口和壁纸页的浮层（摆放提示、工具条、Toast、加载提示、调试面板）用同一套样式。

## 不做

- 不出现游戏里的名称、术语、Logo、立绘，只借风格。
- 不动壁纸内容本身：唱片机组件、天气粒子、自定义元素的样子都不变。
- 不加装饰性的假数据、扫描线、故障闪烁这类"冲击力"效果（skill 里要用户明确要求才开）。

## 设计规则

**形状**：切角，不倒圆角，不用倾斜的平行四边形。
- 卡片 / 面板：左上 + 右下切角 12px；弹窗 16px；缩略图 10px；磨砂浮层 8px。
- 按钮：只切右下角，普通 8px、小按钮 7px、图标按钮 6px。
- 例外：唱片本身是圆的；摆放模式的旋转手柄保持圆点（其余手柄都是方的，圆的一看就是"转"，提示文字里也叫"圆点"）。

**颜色**（`ui/tokens.css`，变量名沿用旧的，`style.css` 不用跟着改）：
- 夜间：底色 `#0f1214` → 卡片 `#1a1f23` → 控件 `#21272c`，侧边栏和标题栏更深 `#0b0d0f`。层级靠明度差，不靠彩色边框。
- 主色天蓝：填充用 `--accent`（`#3cb6f3`），当文字或细线用 `--accent-text`（日间换成深蓝，否则看不清）。只给主要按钮、选中态、开关和数值。
- 黄色只出现在警示条纹里（卸载确认框顶边）。成功 / 警告 / 危险是独立的语义色。
- 卡片、主按钮铺一层很淡的噪点底纹（`--grain`，内联 SVG）。

**字体**（全部自带，SIL OFL）：
- 中文大标题：思源宋体。页面标题 900 / 26px，分组标题 700 / 16px，预览上的壁纸名、唱片机的歌名、弹窗标题。字距 −0.04 ~ −0.05em。
- 英文大写小字（`.en`）：Saira 宽体（`font-stretch: 125%`），字距 +0.18em 左右。只写有意义的词：模块名（WALLPAPER、GALLERY）、天气名、眉题（CONFIRM UNINSTALL）。
- 数值、路径、序号：JetBrains Mono。
- 正文：系统里的思源黑体，没有就用微软雅黑（Windows 自带，够用，不打包）。

**装饰**：默认只有切角、1px 细线、中英混排小字、噪点底纹四种。
- 预览四角的 L 形角标框只框主视觉（壁纸页、视差页的预览）。
- 页面标题下的分隔线起头加粗一小段，分组标题后面一条细线延伸到右边。
- 空预览铺点阵。

**动效**：换页淡入 + 上移 6px（0.24s）；悬停只提亮描边，主按钮多一层淡阴影，不位移、不放大；弹窗从 97% 放大进入；Toast 上移淡入。系统关了动画效果时全部去掉。

## 实现要点

- **切角框 `.cf`**：两个伪元素用同一个 `clip-path`，下层填描边色、上层内缩 1px 填底色；元素本身不裁切，所以内容、焦点框、弹出的问号说明都不会被切掉。用法：加 `cf` 类，用 `--cut`、`--cf-line`、`--cf-bg` 调。
- **缩略图外框**（图库、视频特效）：图片自己 `clip-path` 切角；悬停 / 选中的外框是垫在图下面的伪元素，`box-sizing: content-box` + `aspect-ratio` + `padding: 2px`，正好比图大一圈。45° 切角往外推 2px，切口要长 1.2px 才平行。
- **磨砂浮层 `.glass`**：同样两个伪元素，模糊放在 `::after` 上；浮层本身 `z-index: 0` 让伪元素留在里面。不能给浮层加 `filter` / `opacity` / `isolation`，否则 `backdrop-filter` 读不到下面的壁纸；也不加 `box-shadow`（方形阴影会在切角处露出亮三角）。
- **深度图操作栏**设了 `z-index: 2`：它是切角框（有自己的层叠上下文），问号说明往下弹时要盖住下面的图库。
- **歌单**没用切角框：它是滚动容器，绝对定位的伪元素会跟着内容滚走。改成一行一首、左侧色条。
- **界面主题**：配置 `theme: 'dark' | 'light' | 'system'`（默认 `dark`，不认识的值读成 `dark`）。主进程把它写进 `nativeTheme.themeSource`，设置页的颜色跟着 `prefers-color-scheme` 走；系统按钮那一条（`titleBarOverlay`）和窗口底色在 `nativeTheme` 的 `updated` 里跟着换。壁纸页在 `<html>` 上写死 `data-theme="dark"`：摆放工具条、提示盖在壁纸上，深色更清楚。
- **字体文件**（`ui/fonts/`，约 6.3MB，`build.files` 里本来就有 `ui/**/*`）：
  - 思源宋体可变字重版，来自 `@fontsource-variable/noto-serif-sc` 5.3.1，按 unicode-range 切成 101 片，页面用到哪些字才加载哪几片（`noto-serif-sc.css`，由 `tokens.css` 用 `@import` 引入）。
  - Saira 宽度轴版（`saira-wdth.woff2`，只有拉丁字符）、JetBrains Mono（`jetbrains-mono.woff2`），来自 Fontsource。
  - 三份 OFL 许可证放在同一目录。

## 验证（2026-10-31）

- Electron（复制一份真实配置到单独的数据目录启动，开调试端口截图）：六个页面、带两个元素的元素页、问号说明、卸载确认框、Toast、图库选中态；夜间、日间、820×560 最小窗口（没有横向滚动条）。
- 主题：设置页切日间 → 页面变浅、系统按钮那一条变浅（直接截屏幕看的）、壁纸窗口仍是深色；跟随系统读到这台电脑当前的深色；切回夜间恢复。内置宋体实际加载了（`document.fonts` 里有 5 片已加载）。
- 浏览器预览：摆放模式（提示、选框手柄、工具条）、加载提示、调试面板、Toast，控制台没有报错。
- `npm test` 180 个全过（新增"界面主题默认夜间，不认识的值读成夜间"）。
- 没测：在没装思源字体的电脑上看（宋体已自带，正文会是微软雅黑）；真实拖动摆放元素（只在浏览器预览里看了样子）。
