KIRIE WALLPAPER · INSTALLATION NOTES

Kirie 壁纸 安装注意事项

Windows 安全提示与安全软件设置 · 适用于 v1.5.0 · 2026 年 11 月

先看这里

  1. 安装包没有代码签名，Windows 会提示"Windows 已保护你的电脑"：点 更多信息 → 仍要运行。
  2. 浏览器可能说这个文件"不常被下载"：选 保留。
  3. 装了 360 等安全软件时，壁纸可能挂不到桌面上（会盖住桌面图标）：把 Kirie 加入信任区，或者退出安全软件后重新打开 Kirie。
  4. 只从官方发布页下载，有疑问时可以核对安装包的 SHA-256（见第 1 节）。

01下载和安装前

系统要求

  • Windows 10 或 Windows 11，64 位（x64）。32 位系统、ARM 版 Windows、Windows 7/8 都不支持。
  • 硬盘空间：安装包约 190 MB，装好后约 560 MB。
  • 不需要联网，深度图在本机生成。

只从官方地址下载

官方发布页：https://github.com/ZihengMiao-Colin/interactive-desktop-wallpaper/releases。在 Assets 里下载 Kirie-Setup-1.5.0.exe。别的网站转载的安装包可能被改过，下面这些"放行"的操作只对官方安装包做。

浏览器的下载提示

因为下载的人还不多，Edge、Chrome 可能提示这个文件"通常不会被下载"或"不常被下载"，并把它挡在下载列表里：

  • Edge：在下载列表里把鼠标移到这个文件上，点 … → 保留；如果再弹出提示，点 显示更多 → 仍然保留。
  • Chrome：在下载列表里点这个文件旁边的 保留（或 仍然下载）。

（可选）核对安装包没被改过

在安装包所在的文件夹里按住 Shift 点右键 → 在终端中打开（或"在此处打开 PowerShell 窗口"），输入：

Get-FileHash .\Kirie-Setup-1.5.0.exe -Algorithm SHA256

显示的 Hash 应该是：

2D6375845DA73A3D76F4FDB0F8235362B1DBD070844E6EF545A6938C8EE10E85

只适用于 v1.5.0。以后的版本请以发布页上写的为准。

02Windows 的安全提示

2.1 "Windows 已保护你的电脑"（SmartScreen）

代码签名证书要每年付费购买，Kirie 是个人项目，安装包没有签名，所以第一次运行时 Windows 的 SmartScreen 会认不出发布者，弹出蓝色的提示框：

Windows 已保护你的电脑

Microsoft Defender SmartScreen 阻止了无法识别的应用启动。运行此应用可能会导致你的电脑存在风险。

更多信息

不运行
  1. 点提示框文字下面的 更多信息。
  2. 这时会显示"应用：Kirie-Setup-1.5.0.exe"和"发布者：未知发布者"，右下角多出一个按钮，点 仍要运行。

Windows 已保护你的电脑

应用：Kirie-Setup-1.5.0.exe
发布者：未知发布者

仍要运行不运行

"未知发布者"的意思是没有签名，不是说文件有病毒。这个提示只在第一次运行安装包时出现，装好后的 Kirie 一般不会再提示。

另一种办法：右键安装包 → 属性 → 在"常规"页最下面勾选 解除锁定 → 确定，再双击运行，就不会弹出这个提示。

2.2 "智能应用控制已阻止…"（只有部分 Windows 11 会遇到）

全新安装的 Windows 11 可能开着"智能应用控制"（Smart App Control）。它比 SmartScreen 严格，会直接拦下没有签名的程序，没有"仍要运行"按钮。只有看到这个提示时才需要处理：

  1. 打开 Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置。
  2. 如果显示"开"，可以改成 关，再运行安装包。
注意：智能应用控制是系统级的保护，关掉后其他没签名的程序也不会再被它拦。在部分 Windows 版本上，关闭后要重置或重装系统才能重新打开。请自己权衡，不想关的话就没办法安装 Kirie。

2.3 用户账户控制（UAC）

安装向导里可以选"只为我安装"或"为使用这台电脑的任何人安装"：

  • 只为我安装（推荐）：装到 %LOCALAPPDATA%\Programs\interactive-desktop-wallpaper，不需要管理员权限，不会弹 UAC 提示。
  • 为所有人安装：装到 Program Files，Windows 会弹出"你要允许此应用对你的设备进行更改吗？"，点 是（需要管理员账户）。

Kirie 运行时不需要管理员权限，不要用"以管理员身份运行"打开它。

2.4 Microsoft Defender 报毒

正常情况下 Defender 不会拦 Kirie。如果 Windows 安全中心说发现了威胁并隔离了 Kirie 的文件：

  1. 先确认安装包是从官方发布页下载的，最好按第 1 节核对一下 SHA-256。
  2. 打开 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录，找到这条记录，点 操作 → 允许（或"还原"）。
  3. 重新安装一遍，确保文件完整。

遇到这种情况请生成诊断报告发给开发者（见第 4 节），方便向微软提交误报。

03安全软件（360、火绒、电脑管家等）

Kirie 要把壁纸窗口挂到桌面图标的下面，这一步要把自己的窗口放进资源管理器的桌面窗口里。有些安全软件会把这个操作当成可疑行为拦下来，目前确认会拦的是 360 安全卫士（不是每次都拦）。被拦时电脑和文件都不受影响，只是壁纸的显示方式变了。

3.1 怎么判断被拦了

看哪里正常被拦下（兜底模式）
桌面图标壁纸在图标下面，图标正常显示图标被壁纸盖住看不见，但点原来的位置还能打开
Kirie 设置窗口顶部没有提示显示"壁纸没能挂到桌面上"
诊断报告桌面层：已挂上桌面层：没挂上（兜底模式：壁纸放在所有程序后面）
点"显示桌面"（Win + D）还是壁纸看到的是 Windows 原来的桌面，再点一次恢复

兜底模式下壁纸放在所有程序后面，不会挡住你在用的程序，可以先这样用；想恢复正常就按下面的办法处理。

3.2 办法一：把 Kirie 加入信任区

需要添加的位置（默认的"只为我安装"）：

%LOCALAPPDATA%\Programs\interactive-desktop-wallpaper\Kirie.exe

文件选择框里可以直接把上面这一行粘贴到地址栏，回车就能跳过去。如果安装时改过位置，就去你选的文件夹里找 Kirie.exe。也可以把整个安装文件夹加进去，以后升级不用重新添加。

安全软件大致的位置（不同版本的菜单名可能略有不同）
360 安全卫士主界面 → 木马查杀 → 右下角 信任区 → 添加文件 或 添加目录
360 杀毒主界面 → 设置 → 文件白名单 → 添加文件 / 目录
火绒安全主界面右上角菜单 → 信任区 → 添加文件 / 添加文件夹
腾讯电脑管家病毒查杀 → 信任区 → 添加文件 / 目录
其他找"信任区""白名单""排除项"之类的设置，把 Kirie.exe 或安装文件夹加进去

加好以后要完全退出 Kirie 再打开：右键任务栏右下角托盘里的 Kirie 图标 → 退出，然后从开始菜单或桌面快捷方式重新打开。

说明："加入信任区"能不能让 360 放行，开发者还没有实测过。如果加了还是不行，用办法二。

3.3 办法二：先退出安全软件，再打开 Kirie

  1. 托盘里右键 Kirie 图标 → 退出。
  2. 托盘里右键安全软件的图标 → 退出（360 安全卫士会再问一次，确认退出）。
  3. 重新打开 Kirie，确认设置窗口顶部不再有"壁纸没能挂到桌面上"的提示。
  4. 需要的话再把安全软件打开。

实测退出 360 后 Kirie 能正常挂到桌面上。Kirie 挂上以后再打开 360 会不会有影响、下次开机会不会又被拦，还没有完整测过；如果又出现提示，重复这几步即可。

3.4 其他可能遇到的安全软件提示

  • 安装时弹窗：安全软件可能提示"有程序正在安装 / 修改系统设置"，确认是 Kirie 的安装包后选 允许。
  • 开机自动启动：在 Kirie 的 设置 页打开"开机自动启动"时，安全软件可能提示"有程序要添加启动项"，选 允许。如果开了自启但开机后 Kirie 没出现，去安全软件的"启动项管理 / 优化加速"里看看 Kirie 是不是被禁用了。
  • 其他壁纸、桌面美化软件：Wallpaper Engine、Lively Wallpaper、桌面整理类软件也会改动桌面窗口，和 Kirie 同时开着可能互相影响。出问题时先关掉它们试试。

还是有问题？

在 Kirie 的 设置 页（或托盘菜单 → 问题反馈）点 生成诊断报告，桌面上会出现一个 Kirie-诊断报告-…txt，里面写着桌面层有没有挂上、检测到哪些安全软件和壁纸软件。报告会去掉路径里的 Windows 用户名，但壁纸和音乐的文件名还在，发出去之前可以自己看一遍。把它发给开发者，或在 GitHub 发布页所在的仓库里提 Issue。

如果 Kirie 完全打不开，请发送这个文件：%APPDATA%\interactive-desktop-wallpaper\logs\main.log
